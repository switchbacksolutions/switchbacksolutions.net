## Key Achievements

### One Catalogue, Two Audiences

Each style is written for both people and agents:

- People browse it as a mood board, with websites cross-referenced against print, product, and graphic design
- Agents read it as structured data, with a **DESIGN.md** per style
- Design tokens ship in DTCG, CSS variables, Tailwind v4, and shadcn/ui formats

### Tools for Working with Styles

- **Capture** — screenshots and measures live websites with headless Chrome
- **Lint** — checks pages against each style's fingerprint
- **Agent skill** — an installable skill that picks a style from a project's mood and applies it

### Simple to Run

The site is a static build with no framework, deployed to **Cloudflare Workers**.

## Impact

The guide gives AI agents concrete references to work from, so the interfaces they build can have a point of view instead of falling back to generic output.
